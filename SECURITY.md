# Политика безопасности

## Как сообщить об уязвимости

Не создавайте публичный issue и не публикуйте подробности уязвимости до исправления.

Откройте вкладку **Security** репозитория, в котором найдена проблема, и выберите **Report a vulnerability**. Отчёт будет виден только мейнтейнерам. Если такой кнопки нет, напишите владельцу организации [@mahach666](https://github.com/mahach666) личным сообщением на GitHub.

В отчёте укажите:

- затронутый проект и версию;
- описание проблемы и возможные последствия;
- шаги воспроизведения или пример кода.

Не прикладывайте реальные пароли, ключи, токены и данные клиентов.

## Что вы получите

Мы подтвердим получение отчёта, оценим проблему и сообщим о ходе исправления. Сроки зависят от сложности проблемы, их гарантировать нельзя. После выхода исправления уязвимость можно описать публично; автор отчёта будет указан по его желанию.

## Поддерживаемые версии

Исправления выпускаются для последней опубликованной версии каждого проекта. Для старых версий исправления не гарантируются.
