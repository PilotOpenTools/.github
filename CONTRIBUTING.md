# Участие в проектах Pilot Open Tools

Спасибо, что хотите помочь. Этот документ действует во всех репозиториях организации, если в репозитории нет собственного `CONTRIBUTING.md`.

## Прежде чем начать

- Участвуя, вы соглашаетесь соблюдать [Кодекс поведения](CODE_OF_CONDUCT.md).
- Нашли ошибку или хотите предложить улучшение — сначала поищите в [issues](../../issues) соответствующего репозитория: возможно, тема уже обсуждается.
- Уязвимости не публикуйте в issues, а отправьте по правилам из [SECURITY.md](SECURITY.md).
- Вопросы по использованию лучше задавать по правилам из [SUPPORT.md](SUPPORT.md).

## Сообщение об ошибке

Откройте issue по шаблону «Сообщение об ошибке» и укажите:

- версию проекта и версию Pilot (Pilot-ICE Enterprise, Pilot-BIM, Pilot-Server);
- версию Windows и .NET, если они важны;
- шаги воспроизведения, ожидаемый и фактический результат;
- логи и сообщения об ошибках без паролей, ключей и данных клиентов.

## Предложение улучшения

Откройте issue по шаблону «Предложение». Опишите задачу, которую нужно решить, а не только готовое решение. Для крупных изменений сначала согласуйте подход в issue, чтобы не тратить время на работу, которую не получится принять.

## Pull request

1. Сделайте fork репозитория и создайте ветку от основной ветки (`master` или `main`, смотрите настройки репозитория).
2. Соберите проект и запустите тесты так, как описано в `README.md` репозитория.
3. Вносите минимальные изменения по теме задачи. Не смешивайте с ними форматирование и рефакторинг несвязанного кода.
4. Для изменения поведения добавьте или обновите тесты.
5. Если в репозитории есть `CHANGELOG.md`, добавьте запись в раздел «Не выпущено».
6. Откройте pull request и заполните шаблон: что изменено, зачем и как проверено.

Мейнтейнер может попросить правки. Pull request, который не проходит сборку или тесты, не будет принят.

## Лицензия вклада

Все проекты организации распространяются по [Apache License 2.0](LICENSE). Отправляя pull request, вы подтверждаете, что вправе передать свой вклад и что он распространяется на условиях этой же лицензии (раздел 5 лицензии).
