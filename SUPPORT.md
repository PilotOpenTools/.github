# Поддержка

- **Ошибка** — откройте issue в репозитории проекта по шаблону «Сообщение об ошибке».
- **Идея или запрос функции** — откройте issue по шаблону «Предложение».
- **Вопрос по использованию** — сначала посмотрите `README.md` и документацию в репозитории, затем поищите среди существующих issues. Если ответа нет, создайте issue с вопросом.
- **Уязвимость** — по правилам из [SECURITY.md](SECURITY.md), не в публичных issues.

Проекты развиваются силами сообщества, сроки ответа не гарантируются.
